# ☕ Java Developer Journey

A structured repository for learning and revising **Java Development**, from Core Java fundamentals to Spring Boot, databases, Spring Security, microservices, DSA, and real-world projects.

The goal of this repository is to maintain my **Java learning journey, practice code, interview preparation, and projects** in one place.

---

## 🎯 Goals

* Strengthen Core Java fundamentals
* Master Java Collections and Stream API
* Practice Data Structures & Algorithms
* Learn SQL and database concepts
* Build REST APIs using Spring Boot
* Learn JPA & Hibernate
* Implement Spring Security and JWT
* Understand Microservices architecture
* Build real-world Java projects
* Prepare for Java Developer interviews
